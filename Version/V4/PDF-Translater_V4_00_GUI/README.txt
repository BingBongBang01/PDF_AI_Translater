PDF Translater GUI
V4.0.0
1. 버전 표기를 translate_pdf.py의 __version__ 상수 한 곳에서만 관리하도록 통일.
   gui.py 타이틀과 build_exe.bat의 빌드 파일명이 이 값을 자동으로 읽어 쓴다.
   (이전까지 버전 문자열이 여러 파일에 하드코딩돼 있어 서로 어긋나는 문제가
   있었음 - 예: zip은 v3.84인데 실제 EXE는 v3.82로 빌드되던 문제)
2. "필수사항 설치" 버튼을 4개로 분리: Python 3.12 설치 / Lemonade 설치 /
   패키지(pip) 설치 / 전체 자동 설치(위 3개를 순서대로 실행하는 통합 버튼).
   필요한 것만 골라서 설치할 수 있다. API 키 프레임에 섞여 있던 설치 버튼들을
   "설치 / 환경 설정"이라는 별도 영역으로 분리해 UI를 정리했다.
3. build_exe.bat이 하드코딩된 버전(v3.82) 대신 translate_pdf.py의 버전을
   자동으로 읽어 EXE 파일명을 결정한다 (_get_version.py 헬퍼 사용).

V3.82
0. EXE 빌드 방식을 --onedir에서 --onefile로 변경 (build_exe.bat).
   빌드하면 dist\PDF-Translater-v3.82.exe 파일 '하나'만 생성되며, 이 파일만
   실행하면 콘솔 창 없이 GUI 하나만 뜬다 (--windowed 유지). 배포도 이 exe
   파일 하나만 복사하면 된다. 내부적으로 서브프로세스를 부르는 모든 지점
   (Python 3.12 탐색, pip 설치 등)에 콘솔 억제 플래그(CREATE_NO_WINDOW)를
   빠짐없이 적용해, 어떤 경우에도 별도 터미널 창이 뜨지 않도록 했다.
   실행은 반드시 dist\PDF-Translater-v3.82.exe를 직접 더블클릭할 것 -
   run_gui.bat/PDF-Translater_GUI.cmd로 실행하면 그 배치파일 자체가 cmd
   콘솔을 열어버리므로(이건 EXE와 무관, 배치파일의 특성) 개발/디버그용으로만 쓸 것.
1. (버그수정, 심각) 텍스트 정규화 정규식의 이중 이스케이프 오류로 소문자 't'가
   전부 공백으로 사라지던 문제 수정 (예: "Description"->"Descrip ion"). 원인:
   re.sub(r"[ \\t]+", ...) 의 raw string 안 '\\t'가 탭이 아니라 '\'와 't' 두
   글자로 해석되어 문자 클래스가 "공백 또는 t"가 되어버렸음 -> r"[ \t]+"로 수정.
2. (버그수정, 심각) 표/다단 레이아웃이 번역 후 깨지던 문제 수정. 원인: PDF에서
   서로 다른 셀/컬럼의 텍스트가 pymupdf에 의해 하나의 큰 텍스트 블록으로 묶여
   추출되는 경우가 있는데, 이를 통째로 한 세그먼트로 합쳐 번역·삽입하다 보니
   칸이 비거나 내용이 뒤섞였음. 이제 블록 안 줄들의 왼쪽 시작 x좌표가 들쭉날쭉하면
   (표/다단으로 판단) 줄 단위로 쪼개 각자 원래 위치에 개별 번역·배치한다.
   일반 문단(줄마다 왼쪽 정렬이 동일)은 지금처럼 하나로 합쳐 번역 품질을 유지한다.

V3.81
1. 파일명 축약: 미번역 구간이 많아지면(6개 이상) 파일명을 압축 표기(-MULTIn)로 바꾸고,
   정확한 페이지 목록은 <파일명>.progress.json 사이드카에 저장. 이어서 번역 시 이 JSON을
   우선 읽어 정확히 복원한다 (파일명 길이 제한 문제 해결). PDF와 같은 폴더에 JSON도 있어야 함.
2. API 키 자동 저장/복원: 번역 시작 시 및 창을 닫을 때 API 키/설정을 저장하고,
   다음 실행 시 자동으로 불러온다. 저장 위치: %APPDATA%\PDFTranslaterGUI\config.json
   (base64로 살짝 가려둘 뿐 암호화는 아님 - 개인 PC 로컬 사용 전제)
3. 원문/번역 언어를 콤보박스로 변경 (직접 입력도 가능). 원문 언어 목록 2번째에
   '자동 인식' 추가 - 선택하면 엔진이 언어를 스스로 판별해 번역.
4. (버그수정) --pages로 특정 페이지만 지정해 번역할 때, 나머지 페이지 전체가
   미번역으로 잘못 표시되던 문제 수정 (스코프를 문서 전체가 아닌 지정 범위로 한정).
