V3.81
1. 파일명 축약: 미번역 구간이 많아지면(6개 이상) 파일명을 압축 표기(-MULTIn)로 바꾸고,
   정확한 페이지 목록은 <파일명>.progress.json 사이드카에 저장. 이어서 번역 시 이 JSON을
   우선 읽어 정확히 복원한다 (파일명 길이 제한 문제 해결). PDF와 같은 폴더에 JSON도 있어야 함.
2. API 키 자동 저장/복원: 번역 시작 시 및 창을 닫을 때 API 키/설정을 저장하고,
   다음 실행 시 자동으로 불러온다. 저장 위치: %APPDATA%\PDFTranslaterGUI\config.json
   (base64로 살짝 가려둘 뿐 암호화는 아님 - 개인 PC 로컬 사용 전제)
3. 원문/번역 언어를 콤보박스로 변경 (직접 입력도 가능). 원문 언어 목록 2번째에
   '자동 인식' 추가 - 선택하면 엔진이 언어를 스스로 판별해 번역.
4. (버그수정) --pages로 특정 페이지만 지정해 번역할 때, 나머지 페이지 전체가
   미번역으로 잘못 표시되던 문제 수정 (스코프를 문서 전체가 아닌 지정 범위로 한정).
